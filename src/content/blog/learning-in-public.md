# Why I Want to Learn in Public

Learning something new is exciting, but it is easy to forget the small discoveries and problems that happen along the way. I wanted a simple place to keep those details.

## The process matters

I don't want to share only finished projects. I also want to record what I tried, what confused me, what finally made sense and what I want to explore next.

A progress note can be as simple as:

- One concept understood more clearly.
- A small feature added to a project.
- A bug investigated and fixed.
- A useful page from the documentation.

## Small experiments count

For example, this tiny JavaScript function is not a big project, but it captures a concept I can reuse:

```js
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet('world'));
```

## The goal

I want this site to become a useful record of my B.Tech learning journey — honest, practical and updated as I keep building.
