# Shivam — Portfolio, Blog & Progress Reports

A minimalist, content-driven portfolio built with Astro, TypeScript strict mode, Markdown content collections and plain CSS. It has no UI framework and no Tailwind CSS.

## Requirements

- Node.js **22.23.4 or newer** (required by the current Astro 7 release)
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Astro (usually `http://localhost:4321`).

## Production build

```bash
npm run build
npm run preview
```

The static site is generated in `dist/`.

## Add a blog post

Create a Markdown file inside `src/content/blog/`, for example `my-new-post.md`:

```md
---
title: "My New Post"
description: "A short summary of this article."
pubDate: 2026-11-23
draft: false
tags:
  - learning
  - projects
---

# My New Post

Write your article here. Markdown headings, lists, links, images and fenced code blocks are supported.
```

## Add a progress report

Create a Markdown file inside `src/content/progress/`, for example `day-200-201.md`:

```md
---
title: "Progress Report: Days 200-201"
pubDate: 2026-11-23
dayRange: "200-201"
draft: false
---

# Days 200-201

## What I worked on

- 
- 

## What I learned

Write what you learned.

## Challenges

Write about anything that was difficult.

## Next steps

- 
```

Set `draft: true` to keep an entry out of the public site and RSS feed.

## Personalize the site

Update these placeholders before publishing:

- `src/pages/index.astro`: name, introduction and X link.
- `src/pages/about.astro`: biography and interests.
- `src/components/Footer.astro`: GitHub and X profile URLs.
- `astro.config.mjs`: replace `https://your-portfolio.vercel.app` with your real production URL. This value is used by the sitemap and RSS feed.
- `src/layouts/BaseLayout.astro`: update the site author/title defaults if you change the site owner name.

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Use the Astro framework preset, `npm run build` as the build command and `dist` as the output directory.
4. Deploy the project.
5. Copy the production URL from Vercel into `site` in `astro.config.mjs`.
6. Commit and push that change. Vercel will redeploy automatically.

## Routes

- `/`
- `/blog/`
- `/blog/[slug]/`
- `/progress-reports/`
- `/progress-reports/[slug]/`
- `/about/`
- `/rss.xml`
- Custom static 404 page (`404.html`)

The sitemap is generated by `@astrojs/sitemap`. Markdown code blocks use Astro's built-in Shiki highlighter. The theme toggle is the only interactive browser script.

## Start from the downloaded ZIP

From a terminal in the folder where you saved the ZIP:

```bash
unzip shivam-portfolio.zip
cd shivam-portfolio
node --version
npm install
npm run dev
```

Use `npm run build` to create the production site and `npm run preview` to preview that build locally.

## Troubleshooting

1. **Astro says Node is too old:** install Node.js 22.23.4 or newer, reopen the terminal, and check `node --version`.
2. **`Cannot find package` or missing dependency:** make sure the terminal is in the project root (the folder containing `package.json`) and run `npm install`.
3. **A collection is missing:** check `src/content.config.ts` and make sure the Markdown files are inside the exact `src/content/blog/` or `src/content/progress/` folder.
4. **Invalid frontmatter:** check YAML indentation, quote `dayRange`, use a valid `YYYY-MM-DD` date, and include all required fields.
5. **A new post does not appear:** check that `draft` is `false`, save the file, and restart the dev server if Astro has not refreshed its content collection.
